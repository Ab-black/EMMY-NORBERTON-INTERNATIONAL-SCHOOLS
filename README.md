# Emmy Norberton International Schools: Homepage Concept

A homepage proposal for management review. Plain HTML, CSS and JavaScript, with no build step and no dependencies.

## Run it
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > Deploy from branch `main`, root) to get a shareable link.

## Structure
- `index.html`: all homepage sections
- `css/styles.css`: design tokens (navy, blue, gold) are at the top in `:root`
- `js/main.js`: sticky header, mobile menu, scroll reveal, form validation
- `assets/images/`: drop in real photos (see the README there)

## Content to confirm with the school
- Levels offered (Early Years, Primary, Secondary are proposed placeholders)
- All proposed copy (about text, values, footer statement)
- Phone, WhatsApp, email, opening hours, verified social links (none invented)
- Official logo (currently a text-based EN mark)

## Enquiry form
Frontend prototype only. Nothing is sent or stored. To go live, connect it to a form service or backend (e.g. Formspree, Web3Forms) in `js/main.js`.
